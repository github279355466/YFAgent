## 1. 项目背景与目标

**背景**：应收会计日常需处理对账、立账、收款认领、核销、账龄分析、催收六大环节，手工操作效率低且易出错。

**目标**：
- 32项账龄指标自动计算（分级账龄表、逾期O01~O05、DSO、坏账拨备、TOP10穿透矩阵）
- 4维催收评分排序（金额30%+紧急度30%+历史逾期率20%+坏账20%）
- 对账单自动生成与邮件直发
- 银行回款智能匹配与自动认领

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/ar`（待确认） |
| 调用方式 | 本地TS引擎纯函数计算 |
| ERP取数 | `yfcli_run` fastquery/getMultiple（服务名待 Q-02 确认） |
| 输入 | 应收明细数组 ArDetail[] |
| 输出 | AgingReport / CollectionScore[] |

## 3. 触发关键词

应收、对账、立账、收款、核销、账龄、催收、DSO、坏账拨备

## 4. 输出格式

- 账龄分析报告：32项指标表格 + TOP10穿透矩阵
- 催收评分报告：4维评分排序列表 + 建议动作
- 对账单：PDF/Excel 格式，支持邮件直发

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认
- 不替代业务人员与客户谈判

## 6. 核心能力

1. **销售对账**：按客户规则生成对账单，邮件直发，差异归因
2. **应收立账**：对账结果/来源单据批量立账，自动审核
3. **收款认领**：银行到款智能匹配，自动生成收支单/收款单
4. **收款核销**：规则驱动自动匹配，先校验后执行
5. **应收账龄分析**：32项指标，DSO/逾期/坏账拨备/TOP10穿透矩阵
6. **催收执行**：4维评分排序，自动生成催收函

## 7. 目标用户

应收会计、财务主管、出纳、销售业务员、财务经理、CFO
