# 生产专家 PRD

| 文档版本 | 修改日期 | 修改内容 |
|---------|---------|---------|
| V1.0 | 2026-10-09 | 从 YZCLI 易助专家模块移植 |

## 1. 项目背景与目标

**背景**：生产管理涉及工单进度跟踪、报工统计、良率分析等环节。

**目标**：覆盖工单到报工全流程。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/production`（待确认） |
| 进度 | `summarizeProgress(workOrders, asOfDate)` |
| 报工 | `summarizeWorkReports(entries)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

工单进度、报工统计、良率分析、工时统计、产量汇总

## 4. 输出格式

- 进度汇总表：工单状态分布 + 延期预警列表
- 良率报告：工时/产量统计 + 良率趋势 + 异常批次

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **工单进度跟踪**：工单状态汇总、延期预警
2. **报工统计**：工时/产量聚合、良率计算

## 7. 目标用户

生产主管、车间主任、PMC、质量管理员
