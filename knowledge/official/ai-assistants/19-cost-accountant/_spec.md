## 1. 项目背景与目标

**背景**：成本管理涉及BOM模拟、月结诊断、成本归因、呆滞分析等多环节，需跨模块数据整合。

**目标**：覆盖成本管理全链路，提供确定性计算结果。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/cost`（待确认） |
| BOM展开 | `explodeBom(rootItem, bomRows)` |
| 成本模拟 | `simulateCost(item, materials, prices, params)` |
| 归因 | `calcAttribution(item, current, previous)` |
| 呆滞 | `diagnoseDeadstockBatch(details, asOfDate)` |
| 月结 | `diagnoseMonthEnd(period, exceptions)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

成本模拟、BOM成本、降本、月结检查、关账、成本归因、波动分析、呆滞、库龄

## 4. 输出格式

- 成本模拟报告：三步法成本结构 + 目标毛利反推报价 + 三类降本方案
- 月结诊断报告：四步诊断表 + 异常三级分类
- 归因分析报告：五层穿透归因树
- 呆滞分析报告：6区间账龄分布 + 7维原因诊断

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **BOM模拟成本**：三步法（材料/人工/制造费用）+ 目标毛利反推 + 三类降本方案
2. **成本月结检查**：四步诊断（问题→影响→根因→建议），异常三级分类
3. **产品成本分析**：五层穿透归因（总成本→要素→明细→价差/量差）
4. **库存呆滞料分析**：双条件判定 + 6区间账龄 + 7维原因诊断

## 7. 目标用户

成本会计、财务主管、销售报价、产品经理、采购部、库存管理、PMC
