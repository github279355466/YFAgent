## 1. 项目背景与目标

**背景**：总账管理涉及凭证校验、期末结账、报表生成、内部对账等核心场景。

**目标**：覆盖总账管理核心场景，提供确定性校验与报表能力。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/gl`（待确认） |
| 凭证校验 | `validateVoucher(voucher)` |
| 结账检查 | `checkPeriodClose(status)` |
| 报表生成 | `buildBalanceSheetTemplate()` / `buildIncomeStatementTemplate()` |
| 勾稽校验 | `checkBalanceSheet(report)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

凭证、录入凭证、结账、关账、报表、资产负债表、利润表、内部对账

## 4. 输出格式

- 凭证校验报告：借贷平衡结果 + 异常分录列表
- 结账检查清单：前置条件完成状态
- 财务报表：资产负债表/利润表标准格式
- 勾稽校验结果：差异明细 + 调整建议

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **凭证管理**：借贷平衡校验、审核状态追踪、过账检查
2. **期末结账**：结账前置检查、结转损益摘要
3. **财务报表**：资产负债表/利润表模板生成、勾稽校验
4. **内部往来对账**：内部交易对账与差异调平

## 7. 目标用户

总账会计、财务主管、财务经理、审计人员
