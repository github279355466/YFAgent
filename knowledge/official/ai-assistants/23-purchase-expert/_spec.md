# 采购专家 PRD

| 文档版本 | 修改日期 | 修改内容 |
|---------|---------|---------|
| V1.0 | 2026-10-09 | 从 YZCLI 易助专家模块移植 |

## 1. 项目背景与目标

**背景**：采购涉及询价比价、交期评审、跟催等环节，需快速决策。

**目标**：覆盖询价到交期跟催全链路。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/purchase`（待确认） |
| 比价 | `compareQuotes(items, quotes)` |
| 交期评审 | `reviewDelivery(requirements, params)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

询价、比价、交期评审、采购跟催、供应商选择

## 4. 输出格式

- 比价建议表：供应商排名 + 价格/交期/质量综合评分
- 交期评审报告：预计到料日 + 缺口风险 + 拆批建议

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **新料采购询价**：物料展开 → 供应商推荐 → 比价分析
2. **采购交期评审**：历史×前置期加权 → 工作日历推到料日 → 缺口风险

## 7. 目标用户

采购员、采购主管、PMC、供应链经理
