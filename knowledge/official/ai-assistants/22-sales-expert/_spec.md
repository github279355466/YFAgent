| 文档版本 | 修改日期 | 修改内容 |
|---------|---------|---------|
| V1.0 | 2026-10-09 | 从 YZCLI 易助专家模块移植 |

## 1. 项目背景与目标

**背景**：销售接单涉及PO解析、报价、评审多环节，需快速响应且保证合规。

**目标**：覆盖从客户PO到交付对账全链路。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/sales`（待确认） |
| PO解析 | `parseStructuredPo(params)` |
| 报价 | `generateQuotation(draftId, lines, params)` |
| 评审 | `reviewOrder(pkg, thresholds)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

解析PO、订单底稿、报价、询价、评审、审核订单

## 4. 输出格式

- 订单底稿：结构化JSON + 主数据匹配结果
- 报价单：四象限价格 + 毛利分析 + 反推报价
- 评审结论：通过/驳回/需审批 + 原因说明

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认
- 报价低于底线需审批流程

## 6. 核心能力

1. **订单底稿生成**：结构化PO解析 → 主数据匹配 → 底稿落库
2. **销售报价**：四象限取价链 + 毛利底线 + 反推报价
3. **销售订单评审**：汇聚评审包 → 一致性检查 → 越权四类判定

## 7. 目标用户

销售业务员、销售经理、报价专员、财务审核
