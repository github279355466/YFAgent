# 计划专家 PRD

| 文档版本 | 修改日期 | 修改内容 |
|---------|---------|---------|
| V1.0 | 2026-10-09 | 从 YZCLI 易助专家模块移植 |

## 1. 项目背景与目标

**背景**：计划执行与交付承诺是制造核心链路，需快速准确的齐套与ATP能力。

**目标**：打通计划执行与交付承诺关键链路。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/plan`（待确认） |
| 齐套 | `checkKit(workOrders, bomEntries, availability)` |
| ATP | `calcAtp(input)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

齐套分析、物料齐套、ATP、交付承诺、可承诺交期、拆批

## 4. 输出格式

- 齐套状态表：工单×物料矩阵 + 缺料清单 + 叫料建议
- ATP交期报告：可承诺日期 + 拆批方案 + what-if试算结果

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **物料齐套分析**：BOM展开 → 按优先级分配 → 双维齐套判定 → 叫料建议
2. **ATP交付承诺**：关键链路计算 → 可承诺交期 → 拆批方案 → what-if试算

## 7. 目标用户

PMC、计划员、生产主管、供应链经理、销售业务员
