# 应付会计专家 PRD

| 文档版本 | 修改日期 | 修改内容 |
|---------|---------|---------|
| V1.0 | 2026-10-09 | 从 YZCLI 易助专家模块移植 |

## 1. 项目背景与目标

**背景**：应付管理涉及六大业务循环、14维分析、月结编排，手工操作复杂度高。

**目标**：覆盖应付管理全流程，提供确定性分析与编排能力。

## 2. 数据接口

| 属性 | 值 |
|------|-----|
| 引擎模块 | `yfcli-experts/ap`（待确认） |
| 14维分析 | `analyzeAp(details, params)` |
| 付款优先级 | `calcPaymentPriority(inputs)` |
| 三单匹配 | `performThreeWayMatch(groups, thresholds)` |
| 月结编排 | `planMonthEnd(config)` |
| ERP取数 | `yfcli_run`（服务名待 Q-02 确认） |

## 3. 触发关键词

应付分析、账龄、DPO、付款优先级、排款、三单匹配、差异、月结、关账

## 4. 输出格式

- 14维分析报告：多维度表格 + 趋势图
- 付款优先级列表：4维评分排序
- 三单匹配报告：差异明细 + 建议处理
- 月结计划：5阶段SOP清单

## 5. 安全契约

- 所有数值由确定性引擎计算，LLM不做算术
- 写操作一律先预览后确认

## 6. 核心能力

1. **应付账款全流程**：预付请款/应付立账/暂估冲销/对冲核销/请款付款/传票凭证
2. **应付数据分析**：14维分析
3. **应付月结编排**：5阶段SOP

## 7. 目标用户

应付会计、财务主管、采购部、出纳、财务经理
