# 易飞库存月档字段语义与期末计算公式

> 用途：T-14 视图 DDL 的直接依据。全部结论来自 **INV2-003.SDD 官方字段定义** + **实库探针实测**（`172.16.2.86:1433` / `SDDEMO93`）。
> 实测时间：2026-10-09。字段中文名以官方 SDD 为准，`knowledge/data-dictionary/field-index.csv` 对本批表**未收录**。

## 一、涉及的六张月档/统计表

| 表名 | 官方文件名 | 维度 | 行数 | 有数量 | 有成本 |
| --- | --- | --- | --- | --- | --- |
| `INVLB` | 品号每月统计档【Item Monthly Summary】 | 年月 + 品号 | 384 | `LB003` | `LB004` |
| `INVLN` | 品号每月统计批号档 | 年月 + 品号 + 批号 | **0（空表）** | `LN004` | `LN005` |
| `INVLC` | 品号每月统计单身【Item Monthly Summary Lines】 | 年月 + 品号 + 仓库 | 328 | `LC004` | `LC005` |
| `INVLE` | 品号每月统计子单身【Item Monthly Summary Sub Lines】 | 年月 + 品号 + 仓库 + 库位 + 批号 | 371 | `LE006` | **无** |
| `INVMC` | 品号仓库档 | 品号 + 仓库（**当前时点**） | 873 | `MC007` | `MC008` |
| `INVML` | 品号仓库批号库位档 | 品号 + 仓库 + 库位 + 批号（**当前时点**） | 1019 | `ML005` | **无** |
| `INVLA` | 库存异动明细档 | 品号 + 日期 + 单别 + 单号 + 序号 | 2332 | `LA011` | `LA013` |

**关键区分**：

- `INVMC` / `INVML` 是**当前时点**（现有库存量），不是历史月档 —— 与 `templates.ts` 中 `JSKLOA` 的语义一致。
- `INVLB` / `INVLN` 是**月初**统计档（只存月初值）。
- `INVLC` / `INVLE` 是**月变动**统计档（存月初 + 本月各类出入库），**没有存期末列，期末必须自己算**。

## 二、INVLC 逐列语义（官方定义，类型 6 月档/统计）

主键：`LC001 + LC002 + LC003`（品号 + 年月 + 仓库）

### 2.1 数量/金额成对列

| 列 | 官方字段名 | 类型 |
| --- | --- | --- |
| `LC004` / `LC005` | 月初数量 / 月初成本 | N16.6 / N16.2 |
| `LC006` / `LC007` | 本月入库数量 / 金额 | N16.6 / N16.2 |
| `LC008` / `LC009` | 本月销货数量 / 金额 | N16.6 / N16.2 |
| `LC010` / `LC011` | 本月领料数量 / 金额 | N16.6 / N16.2 |
| `LC012` / `LC013` | 本月调拨(入)数量 / 金额 | N16.6 / N16.2 |
| `LC014` / `LC015` | 本月调整(入)数量 / 金额 | N16.6 / N16.2 |
| `LC016` / `LC017` | 本月出库数量 / 金额 | N16.6 / N16.2 |
| `LC018` / `LC019` | 本月销退数量 / 金额 | N16.6 / N16.2 |
| `LC020` / `LC021` | 本月退料数量 / 金额 | N16.6 / N16.2 |
| `LC022` / `LC023` | 本月调拨(出)数量 / 金额 | N16.6 / N16.2 |
| `LC024` / `LC025` | 本月调整(出)数量 / 金额 | N16.6 / N16.2 |

### 2.2 成本四要素（**不可加进期末公式**）

| 列 | 官方字段名 |
| --- | --- |
| `LC026` | 本月成本-材料 |
| `LC027` | 本月成本-人工 |
| `LC028` | 本月成本-制费 |
| `LC029` | 本月成本-加工 |

实测：四要素**不能**加进期末成本公式（加进去仅 88/141 吻合）。它记录的是**成本构成拆解**，与 `INVLA.LA017~LA020`（金额-材料/人工/制费/加工）同源，仅作成本分析维度。

实测恒等式（328/328 行成立）：

```
LC026 + LC027 + LC028 + LC029 = 本月成本变动额
```

### 2.3 包装数量列（`LC030`~`LC040`）

月初包装数量 + 本月入库/销货/领料/调拨(入)/调整(入)/出库/销退/退料/调拨(出)/调整(出)包装数量。

实测**不满足**数量列的符号链式公式（仅 19/328 吻合），推测因包装单位换算（`INVMC.MC014` 库存包装数量、`INVLA.LA021`）导致。**建议：首版视图不实现包装口径**，待真实启用包装管理的环境复核。

### 2.4 预留列

`LC041` char(1) / `LC042` char(8) / `LC043` varchar(30) / `LC044`~`LC046` numeric —— 实测全空或全零。

## 三、INVLE 逐列语义（子单身）

主键：`LE001 + LE002 + LE003 + LE004 + LE005`（品号 + 年月 + 仓库 + 库位 + 批号）

- `LE006`~`LE027`：**奇数位是数量**（月初/入库/销货/领料/调拨入/调整入/出库/销退/退料/调拨出/调整出），**偶数位全是成本但恒为 0**。
  官方字段名写「预留字段」，备注列却写「月初成本」「本月入库金额」—— 即**设计上预留但未启用**。
- 实测全部成本列与四要素列（`LE007`/`LE009`/…/`LE031`）**恒为 0**（371 行全零）。
- `LE032`~`LE042`：包装数量列（同 2.3）。
- `LE043`~`LE048`：预留列。
- 与 `INVLC` 的**错位关系**：`LE(n) ↔ LC(n-2)`（实测 328/328 命中），即 `LE006=LC004`、`LE008=LC006`…

**结论：`INVLE` 只有数量，没有成本。**

## 四、期末计算公式（★ 视图 DDL 核心）

### 4.1 数量

```sql
期末数量 = 月初数量
         + 本月入库数量 - 本月销货数量 - 本月领料数量
         + 本月调拨(入)数量 + 本月调整(入)数量
         - 本月出库数量 + 本月销退数量 + 本月退料数量
         - 本月调拨(出)数量 - 本月调整(出)数量
```

`INVLC` 版本：

```sql
LC004 + ISNULL(LC006,0) - ISNULL(LC008,0) - ISNULL(LC010,0)
+ ISNULL(LC012,0) + ISNULL(LC014,0) - ISNULL(LC016,0)
+ ISNULL(LC018,0) + ISNULL(LC020,0) - ISNULL(LC022,0) - ISNULL(LC024,0)
```

`INVLE` 版本：

```sql
LE006 + ISNULL(LE008,0) - ISNULL(LE010,0) - ISNULL(LE012,0)
+ ISNULL(LE014,0) + ISNULL(LE016,0) - ISNULL(LE018,0)
+ ISNULL(LE020,0) - ISNULL(LE022,0) - ISNULL(LE024,0) - ISNULL(LE026,0)
```

### 4.2 成本

```sql
期末成本 = 月初成本
         + 本月入库金额 - 本月销货金额 - 本月领料金额
         + 本月调拨(入)金额 + 本月调整(入)金额
         - 本月出库金额 + 本月销退金额 + 本月退料金额
         - 本月调拨(出)金额 - 本月调整(出)金额
```

`INVLC` 版本：

```sql
LC005 + ISNULL(LC007,0) - ISNULL(LC009,0) - ISNULL(LC011,0)
+ ISNULL(LC013,0) + ISNULL(LC015,0) - ISNULL(LC017,0)
+ ISNULL(LC019,0) + ISNULL(LC021,0) - ISNULL(LC023,0) - ISNULL(LC025,0)
```

### 4.3 实测验证方法与结果

**方法**：链式校验 —— 同一 `(品号, 仓库)` 的「上月期末」应等于「本月月初」。仅取**年月连续相邻**的对（`年月 = 上月 + 1`），避免跳月行干扰。

| 校验项 | 对数 | 吻合 |
| --- | --- | --- |
| 成本链式（4.2 公式，符号方案 A） | 141 | **141 / 141** ✅ |
| 成本链式（方案 B：销退/退料取负） | 141 | 129 / 141 |
| 成本链式（方案 C：全加） | 141 | 110 / 141 |
| 成本链式（方案 D：全反向） | 141 | 88 / 141 |
| 数量链式（4.1 公式，符号方案 A） | 141 | 140 / 141 |
| 数量链式（含四要素） | 141 | 88 / 141 |

**符号方向已确定**（方案 A）：入库/调拨入/调整入/销退/退料 取**加**；销货/领料/出库/调拨出/调整出 取**减**。

数量侧唯一失配行已溯源为测试库 1 单位尾差（该笔在 `INVMC` 已冲销为 0）。

### 4.4 ★ 不要用 INVLB + INVLA 算期末

实测「`INVLB` 月初 + `SUM(INVLA` 期间异动 × `LA005` 符号)`」与 `INVLC` 期末的匹配率仅 **数量 190/212、成本 182/212**。

失败根因：

1. **维度粒度不同** —— `INVLB` 是品号级，`INVLC` 是品号+仓库级。品号级汇总会掩盖仓库间调拨。
2. **数据区间不一致** —— `INVLA` 覆盖到 202609，`INVLC` 只到 202506。

**必须直接用 `INVLC` 的公式**，不要自己拿 `INVLA` 汇总。

## 七、单别码关联（用户 2026-10-09 裁决）

一种单据可以有多个单别，**单别 + 单号 = 唯一 key**。单别本身不等于单据类型，需经 `CMSMQ` 关联：

```sql
SELECT a.LA006 AS order_type_code, m.MQ003 AS doc_category
FROM INVLA a
LEFT JOIN CMSMQ m ON m.MQ001 = a.LA006
```

`CMSMQ` 表结构：`MQ001` char(4) 单别 / `MQ002` char(20) / `MQ003` char(2) 单据类型。

实测 `INVLA` 出现的单别 **100% 可关联成功**，映射示例：

| 单别 `LA006` | 单据类型 `MQ003` |
| --- | --- |
| 2301 / 2302 / 2309 | 23 |
| 3401 / 3402 / 3403 / 3404 | 34 |
| 1101 / 1102 / 1107 / 1108 / 1109 | 11 |
| 1201 / 1202 | 12 |
| 5401 | 54 |
| TZ01 | 25 |

> 销货出库成本口径 = `MQ003` 判定为销货类 **且** `LA005 = -1`（出库）。两者必须同时锁定，只过滤入出别会混入领料成本。
