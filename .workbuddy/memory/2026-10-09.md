## 六、架构裁决：易飞与易助统一为双通道（本日最重要结论）

用户指出 YFAgent 应与 YZCLI 架构一致，我此前「易飞不提供数据库直连」的说法**是错的** —— 文档 `phase1-sdk-plan.md:433` 原文写的是「OPEN 项，不是既定方案」，我把自己的臆断当成了既有结论。已实测证实直连可用。

**实测环境**：`172.16.2.86:1433` / `SDDEMO93` / `ai` / SQL Server 2014 (SP2)。1211 张表，单 schema `dbo`，仅 4 个视图（`MoJu` / `VCMSMQZ` / `VCOPTH` / `VMOCTE`），**无 `vw_ai_*`**。

**架构对比结论**：CRUD 走 OpenAPI 两条产品线一致；唯一差异是 YFAgent **缺 analysis 层**（YZCLI 有 11 个子模块 + 20 个 SQL 模板 + 9 个只读视图）。我用离线 CSV 顶替了 analysis 层的位置 —— 属替代方案，不是架构对应物。

**表名 100% 一致**（此前我误判为不同命名体系）：3 位前缀交叉比对 52 组，52 组一致 / 0 组不同。库表名与字典表名同名（`ACMLC` / `ACMMA` / `ACMMO`），**无需映射层**。

**COMPANY 裁决**：用户明确 —— `COMPANY` 是预留管理字段，无业务含义；易飞为独立公司账套，不存在一表多账套。**视图不带 COMPANY 过滤**。（探针曾发现 `ACMLC` 有 SDDEMO93/92/91 三个值，确认为预留字段历史遗留值，不构成隔离依据。）

## 八、字段级映射验证完成（85/85）

**关键方法论突破**：`knowledge/data-dictionary/field-index.csv` 含 `column_cn` 中文字段名（54843 行），
可以做**语义级映射**，不必靠字段序号猜测。配合 `YZCLI/packages/yzcli-analysis/src/runtime/sql/templates.ts`
的注释（记录了每个易助字段的业务含义），构成权威双证据链。此前我按「字段位置+类型」推断的做法应废弃。

**映射结果三分类**（16 张表 / 85 字段）：
- **69 直接对应**（绿）—— 库存/采购/会计/应收应付主干字段基本整齐
- **12 需换列**（黄）
- **4 无等价列**（红）

**P0 阻塞 2 项**：
1. `JSKLPB.LPB005`（期末成本）→ `INVML` 无成本列。实测 1019 行中仅 `ML005`（库存数量，341 非零）
   与 `ML012`（346 非零，**字典无中文名，疑为成本**）有值；`INVLN` 是空表（0 行）且无仓库维度。
   阻塞 4 个时点库存模板。**待确认 ML012 语义**。
2. `JSKLNA.LNA018`（销货客户）→ `INVLA.LA024`「对象」语义混杂：实测含客户名（天之蓝海更蓝）、
   供应商名（第一波供应商）、关联单号（5102-20260920002）三类值。**改 JOIN COPTG.TG004**。

**重要实测发现（推翻若干假设）**：
- ★ `LNA035/036/037`（人工/制费/委外）**有等价列**：`INVLA.LA018 金额-人工`(174 非零) /
  `LA019 金额-制费`(174 非零) / `LA020 金额-加工`(229 非零)。此前担心的「易助特有列」不成立。
  但**无独立委外列**（委外归入加工），口径需业务确认。
- ★ `LNA015`（加减项 ±1）**不需单独映射**：`INVLA.LA005 入出别` 就是 numeric ±1（1:1174 / -1:1158）。
  SQL 去掉 `LNA015` 乘数，改乘 `LA005`。
- ★ `LNA004` 类型升级：易助是 `'I'/'O'` 字符，易飞是 numeric ±1 —— 可直接用 `LA005` 替代，
  但**不能再叠加 `LNA001` 数字码**（易飞是 `LA006 单别` char(4)，实测 130+ 种值：2301/023w/5401/5501/TZ01…），
  **必须建单别码对照表**，这是 gross_profit 成本口径的前置条件。
- ★ 收入口径陷阱：易飞 `COPTG.TG045`/`COPTH.TH013` 虽名为「金额」但**是含税**。
  实测单号 20260911001：TG045=10176.99（含税）、TG045-TG046=8853.98（无税）、TH013=10000（含税）、TH037=8849.56（税前）。
  易助 `KEA023`/`KEB012` 要的是**无税收入** → 必须改用 `TG045-TG046` 或 `TH037`。
- ★ 审核码取值：易助仅 `'T'`；易飞实测 **Y/N/V 三值**（ACRTK Y94/N53/V4、ACPTK Y79/N122/V18/U1、
  PURTG Y192/N108/V2、PURTC Y281/N168/V14）。模板默认值须从 `'T'` 改 `'Y'`，V 含义待确认。
- `ACTLE` 年度/期间是分离列：`LE002`=4 位年（2026）、`LE003`=2 位期间（04）；`LE014`=借方本币、`LE017`=贷方本币。
- `INVML.ML004` 批号是**真实值**（如 `PA2-1`/`WPB-1`），优于易助 `LPB012` 全掩码问题。
- `CSTTA` 成本四要素 `TA015~TA018`（本期投入材料/人工/制造费用/加工费用）齐备。
