## 一、当日关键决策（需长期记住）

### 1. 三条用户修正（覆盖我的初始判断）

| 我的初判 | 实际 | 教训 |
|---|---|---|
| Token 获取是阻塞项 | **只需配置文件填值**，Header 三头与易助逐字一致 | 别把「文档未写获取途径」当阻塞 |
| 易飞无 AI 私有端点 | **有 22 个助手走 `yf.ai.*` 服务端直调**，与易助同构 | Apipost 只收录标准 OpenAPI，私有端点不在其中 |
| 需要兼容层做 conditions 转换 | **按产品线彻底分包**，不做兼容 | 差异已足够大，兼容层成本高于收益 |

### 2. 已实测确认的易飞特性（推翻常识）

| 项 | 结论 |
|---|---|
| 字段命名 | `表名[3:5] + 3位序号`（**并集判据**，单侧会误判 50 或 11 条） |
| 字段名语义 | **无语义**（`TC001` 非 `doc_type_no`），SDK 必须内置字典层 |
| 管理字段 | **网关注入**，底层表无这些列（54842 字段中仅 3 次登记） |
| `node_name` | 用**逻辑节点名**（`*_data`），已验证 110/175 可用 |
|枚举 | 回参是「编码.中文」，**查询只认纯编码**（混用返回空集且 `code=0`） |
| 错误 token | 返 **HTTP 500 + HTML**，非 JSON |
| 主键全错 | 返 `code=0` + **空数组**（不报错） |
| `MD008` | **格式掩码**（含 `[FORMATE:YMD]` 979 行官方标注），非代码表 |

### 3. 本项目工程纪律（违反必返工，详见 AGENTS.md）

- 写含反引号的中文文本 → **必须落文件再执行**，禁止 `python -c` 内联（已炸 3 次，含 46 MB 文件被当脚本跑、孤儿进程 57 分钟）
- 生成脚本写文件 → 禁止 `(CR+LF).join(str)` 逐字符拼接（已炸 2 次）
- 统计数字 → **必须带口径标签**，禁止裸数字与跨口径相减（曾产生 9 个版本数字）
- 破坏性验证 → 只在副本上做
